# Standard Roman Urdu spellings

The checker (`scripts/check_roman_urdu.py`) auto-fixes only the **unambiguous** variants below; short ones like "he", "q", "b" or "kam" depend on context, so Claude fixes those by reading the sentence.

| Use this | Not these | Meaning |
|---|---|---|
| hai | hy, hay, he, hae | is |
| hain | hen, hein, hayn | are |
| nahi | nhi, nai, nahin, nhn | no / not |
| kya | kia, kyaa | what |
| kyun | kyon, q, kiun | why |
| mein | mien | in |
| main | mein (for "I" only when clear) | I |
| aap | ap, aapp | you (respectful) |
| bhi | b, bi | also |
| abhi | abi, abhe | now |
| theek | thik, theak, thk | okay |
| zaroor | zarur, zror | surely |
| shukriya | shukria, shukrya, sukriya | thanks |
| kaam | kam (when "work") | work |
| bohat | bht, bahut, bhot | very |
| kar | ker, kr | do |
| raha | rha, rahaa | -ing (m) |
| rahi | rhi | -ing (f) |
| sakta | skta, sakhta | can |
| chahiye | chahye, chaiye, chahie | should / need |
| liye | liay, lie, liyea | for |
| saath | sath, saat | with |
| pehle | phle, pehly, pehlay | before |
| baad | bad (when "after") | after |
| jaldi | jldi, jaldy | quickly |
| zyada | ziada, zada, ziyada | more |
| thora | thoda, thra | a little |
| mujhe | mjhe, mujhy, mhuje | to me |
| humein | hamein, hume | to us |
| unhein | unhe, unhen | to them |
